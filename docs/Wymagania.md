# Wymagania projektu 


To przed tymi dwoma taskami:
- Filmy wzorcowe - nagrywamy lub/i bierzemy z internetu.
- Zrobić moduł, który będzie zlicza dane np. oblicza kąty itd. 
- Rejestracja biomechaniki - tego jak ktoś się rusza. 
- Filmy testowe z błędami
- Zdefiniować błędy w ćwiczeniach
- Uczenie modelu kiedy jest powtórzenie - jeżeli model uzna, że dane powtórzenie jest dobre 


System ma robić dwa taski: 
1. liczyć powtórzenia -- to robimy jako pierwsze
2. rozpoznawać błędy.
